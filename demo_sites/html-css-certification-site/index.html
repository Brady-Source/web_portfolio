About Me

I'm Brady Finnell, the creator behind EminenceV2 Productions. What started as a hobby shooting timelapses and cutting motion graphics reels has grown into a full production pipeline covering cinematic intros, VFX compositing, and custom video editing for creators and brands.

Outside of the edit bay, I'm a Marine transitioning into software engineering and AI/ML development, so this site itself is hand-built with plain HTML and CSS — no frameworks, no shortcuts. I care as much about clean code as I do about clean cuts.
